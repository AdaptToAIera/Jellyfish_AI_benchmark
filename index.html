What the benchmark actually showsČo benchmark v skutočnosti ukazuje

This benchmark is not a general intelligence test. It is a practical test of how models reason through a small creative-programming task. The prompt does not ask for a framework, a library, or an explanation. It asks for one working HTML canvas. That is why the differences are so visible: weaker outputs draw an ellipse, add glow, and let it float. Stronger outputs think in layers: background, particles, light, bubbles, jellyfish, depth, interaction, and performance.

Tento benchmark nie je test všeobecnej inteligencie. Je to praktická skúška toho, ako modely rozmýšľajú pri malej kreatívno-programátorskej úlohe. Prompt nežiada framework, knižnicu ani vysvetlenie. Chce jeden funkčný HTML canvas. Práve preto sú rozdiely také viditeľné: slabšie výstupy nakreslia elipsu, pridajú glow a nechajú ju plávať. Silnejšie výstupy rozmýšľajú vo vrstvách: pozadie, častice, svetlo, bubliny, medúzy, hĺbka, interakcia a výkon.

Cloud models are generally more consistent: none of the comparable cloud outputs failed the basic runtime check. Local models show a wider spread, but the best local entries are no longer merely “good for local.” Qwen38 27B Q8 and GLM 53 IQ4 XS are strong enough to compete with, and in some visual aspects beat, several cloud outputs.

Cloudové modely sú všeobecne konzistentnejšie: žiadny z porovnateľných cloudových výstupov nezlyhal v základnej runtime kontrole. Lokálne modely majú väčší rozptyl, ale najlepšie lokálne výstupy už nie sú iba „dobré na lokálny model“. Qwen38 27B Q8 a GLM 53 IQ4 XS dokážu konkurovať viacerým cloudovým výstupom a v niektorých vizuálnych aspektoch ich aj prekonať.

How to add the next testAko pridať ďalší test

The article is data-driven. To add a new model, put its HTML output into models/ and add one record to data/models.json. Ranking, table, cards, filters, and live previews are generated from that data.

Článok je postavený dátovo. Nový model pridáš tak, že jeho HTML výstup vložíš do models/ a doplníš jeden záznam do data/models.json. Rebríček, tabuľka, karty, filtre aj živé náhľady sa generujú z týchto dát.
